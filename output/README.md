## 파일

- `brand-report.md` — 인터뷰 단계 1 결과 (포지셔닝·브랜드 4축·핵심 카피)
- `content-inventory.md` — 인터뷰 단계 2 결과 (콘텐츠 인벤토리·섹션 카피 초안)
- `design-brief.md` — 인터뷰 단계 3 결과 (컬러·타이포·레이아웃)
- `site/` — 절차 B(HTML 생성) 결과

  - `styles.css`
  - `assets/` — 이미지
