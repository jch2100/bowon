# input/ — 사용자가 자료를 두는 곳

여기에 둔 파일은 인터뷰 중 AI가 참고합니다.

## photos/

프로필·강의·로고 등 이미지. 형식 자유 (jpg/png/webp).

권장 파일명:
- `profile.jpg` — 대표 프로필 사진
- `logo.png` — 개인 로고가 있다면
- `program-1.jpg`, `program-2.jpg` — 프로그램·강의 사진
- 그 외 자유롭게

## sources/

텍스트 자료. 인터뷰 답변을 보강합니다.

권장:
- 블로그 글 복사본 (`.md` 또는 `.txt`)
- 이력서·약력 (`.pdf` 또는 `.md`)
- 외부 매체 기사·인터뷰
- 강의 후기·평가서

## 주의

- 여기 둔 파일은 그대로 GitHub에 올라갑니다 (개인정보 주의).
- 민감한 정보(주민번호·계좌번호 등)는 절대 두지 마세요.
- 제3자 저작권 자료(다른 사람 사진·글)는 사용 권한이 있을 때만.
