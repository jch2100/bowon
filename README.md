# bowon

이 저장소는 **이보원 강사** 소개 웹페이지 배포용 저장소입니다.

## 바로 보기

- 메인 페이지 파일: `index.html`
- 스타일 파일: `styles.css`
- 이미지 폴더: `assets/`

## GitHub Pages

GitHub Pages를 켜면 이 저장소의 루트 `index.html`이 웹사이트 첫 화면으로 열립니다.

설정:

1. GitHub 저장소에서 `Settings`
2. 왼쪽 메뉴 `Pages`
3. `Deploy from a branch`
4. `main` / `root` 선택 후 저장

## 참고

- 작업용 원본 산출물은 `output/` 아래에도 보관되어 있습니다.
- 실제 배포 기준 파일은 저장소 루트의 `index.html`, `styles.css`, `assets/` 입니다.
